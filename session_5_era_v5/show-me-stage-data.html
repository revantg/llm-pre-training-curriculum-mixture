What data goes into each stage

There are two stage lists. The lifecycle is the whole V5 run. The curriculum is only the diet inside pretraining plus the anneal. Session 5 decides both. Later stages do not eat the same pile.

The mistake

Wrong One mixed corpus. Pour it into pretrain, then SFT, then reasoning, then preference.
Same documents. Different stage names. The model never learns a new objective.
Right Each stage gets a different shape of example and a different loss. Pretrain gets documents. Anneal gets the reserved best documents. SFT gets (instruction, response). Reasoning gets long traces, then a verifier. Preference gets chosen/rejected pairs.

1. Lifecycle — the whole run

Stage 1 · ~95% of tokens

Pretrain

  • Raw documents: web, code, STEM, Indic
  • Some short reasoning, some packed long-ctx
  • Cheap function-call format only
Loss: every token · next-token CE
Stage 2 · ~2%

Anneal

  • Held-back Tier A
  • Verified Indic
  • Long agent trajectories
  • Long reasoning traces
Same CE · best data · low LR
Stage 3 · <1%

SFT

  • (instruction, response)
  • Not the web crawl
Loss: response only
Stage 4 · <1%

Reasoning

  • Long CoT traces first
  • Then RLVR: prompt + verifier
Then: reward only, no CE
Stage 5 · <1%

Preference

  • chosen vs rejected
DPO · not documents
Stage 6

Serve

  • No data in
Frozen weights

Session 5 writes the recipe for the two wide blocks. Stages 3–5 are reserved now and spent later. Do not dump long CoT or SWE trajectories into stage 1 and call it done.

2. Curriculum — diet inside pretrain + anneal

Same document-shaped data. Different mix over time. Web starts fat and thins. Hard / scarce lanes climb. The best tokens appear only at the end because you held them.

3. One lane, two different objects

Agentic
Do not pass the same file to every stage.

Pretrain Glaive, xLAM, ToolACE, ToolBench — short calls. Teaches JSON format. Observations masked.

Anneal SWE-Gym, SWE-smith, OpenHands — long plan / fail / recover traces. Tier A. Held until now.

SFT / later Full assistant trajectories again, response-masked. Not the 0.63B unique pile dumped twice.

Reasoning
A distribution of lengths, then a different objective.

Pretrain Short and medium traces mixed in at 6%. Structure only.

Anneal Long traces reserved from OpenThoughts / OpenR1 / AON.

Stage 4 First long-CoT SFT (problem grey, trace green). Then RLVR: prompt + verifier, no token loss.
